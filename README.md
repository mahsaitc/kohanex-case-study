# KOHANEX — Bilingual B2B Sourcing Platform

> **Note:** This repository is a documentation-only case study. KOHANEX is a client project; the production codebase is proprietary to the client and is not published here.

## Overview

A bilingual (English/Persian) corporate website for KOHANEX, a B2B sourcing and business-facilitation company connecting international buyers with verified Iranian suppliers. Delivered as a freelance project (via Ponisha).

**Live site:** https://kohanex.com

## My Role

Full-cycle freelance development: architecture, build, bilingual localization, SEO, security hardening, and client handover.

## Tech Stack

- WordPress
- Astra (theme)
- Elementor (page builder)
- WPML + WPML String Translation (bilingual EN/FA, RTL)
- Contact Form 7 (custom bilingual inquiry forms)
- PHP (custom mu-plugin for site-specific logic)

## Key Features

- Full English/Persian localization with WPML, including RTL layout and a dedicated Persian inquiry form independent from the English one
- Client-approved terminology system applied consistently across both languages
- Custom mail-tag logic and spam protection (honeypot) on inquiry forms
- SEO setup (Yoast), structured data, and sitemap submission for both languages
- Security hardening (login-attempt limiting, admin access review, SSL)
